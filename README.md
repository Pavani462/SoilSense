# Soil Fertility Prediction System

## Project workflow

Dataset → Pre-processing → Model Training → Model Comparison → Best Model → Fertility Prediction

## Dataset

`data/dataset1.csv`

The dataset contains 880 soil samples and the following soil parameters:

- N
- P
- K
- pH
- EC
- OC
- S
- Zn
- Fe
- Cu
- Mn
- B

Target:

- 0 = Less Fertile
- 1 = Fertile
- 2 = Highly Fertile

## Primary experiment

The project's core experiment uses:

`N + P + K + pH → Fertility`

Two classifiers are trained:

1. Random Forest
2. Gradient Boosting

Evaluation metrics:

- Accuracy
- Weighted Precision
- Weighted Recall
- Weighted F1-score
- Classification report
- Confusion matrix

## How to run

Open this folder in VS Code.

### 1. Create a virtual environment

Windows:

```bash
python -m venv .venv
.venv\Scripts\activate
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Analyze the dataset

```bash
python src/01_data_analysis.py
```

### 4. Preprocess and create the train/test split

```bash
python src/02_preprocessing.py
```

### 5. Train the models

```bash
python src/03_train_models.py
```

### 6. Evaluate and compare the models

```bash
python src/04_evaluate_models.py
```

### 7. Test a sample prediction

```bash
python src/05_predict_fertility.py
```

## Important

Do not enter model performance values manually into the report. Use the actual values generated by `04_evaluate_models.py`.

The next development stage is SHAP explainability and What-If analysis.
